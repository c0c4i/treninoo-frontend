# Treninoo — sito web

Landing page di [Treninoo](https://github.com/c0c4i/treninoo), l'app per cercare treni, soluzioni e stazioni.

## Sviluppo

```sh
npm install
npm start      # build + server locale con live reload
npm run build  # genera il sito in dist/
```

I sorgenti sono in `src/` (Pug, SCSS, JS, asset); `dist/` è generato.

Basato sul template [New Age](https://github.com/StartBootstrap/startbootstrap-new-age) di Start Bootstrap (MIT).
